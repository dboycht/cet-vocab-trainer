# 四六级词汇刷词器

从「大学英语六级词汇乱序版」PDF 提取出 **2083 个词条**，做成一个**完全离线**的刷词应用：
**客观判分的测验主线**（三种题型）+ 快速过词 + 乱序浏览 + 学习统计。

不做账号、不联网、不上传任何数据 —— 学习进度只存在你自己浏览器的 localStorage 里。

---

## 为什么是「选出答案」而不是「自己打分」

自评卡片（看英文 → 翻出中文 → 问自己记住没）测的是**再认**：看到答案才觉得
"这个我会"。熟悉感不等于回忆，而且**你没法证伪自己** —— 自评几乎永远不会失败。

所以主线的每一题都要你**产出**答案，由程序判对错：

| 题型 | 你看到 | 你要做 |
| --- | --- | --- |
| 英 → 中 | `mischief` | 4 个中文释义里选出对的 |
| 中 → 英 | `n.调皮，捣蛋，胡闹` | 4 个英文单词里选出对的 |
| 拼写 | `n.调皮，捣蛋，胡闹` | 把 `mischief` 完整打出来 |

干扰项**优先同词性、长度接近**，不让你靠"词性/长度"排除。拼写答错时会标出你错在哪一处。

### 判分规则（防的是「自己骗自己」）

| 档 | 触发 | 对排期 |
| --- | --- | --- |
| **不认识** | 答错 | 掉回学习中，今天再来 |
| **模糊** | 答对，但**本轮内这个词你答错过**（刚看过答案）；或选择题答得超时 | 间隔 ×1.2 |
| **认识** | 答对，且本轮没答错过、也不超时；**拼写题打对一律算认识**（打字慢不算不会） | 间隔 ×熟练度 |

两条关键设计：

- **新词第一次只「教」不「考」** —— 从没见过的词让你 4 选 1 是纯蒙，测不出东西。
  首轮展示 + 朗读，排到明天，**第二次见面才开始算成绩**。
- **「记住了」是硬判据**：连对 ≥3 次 **且** 这 3 次跨了至少两天。
  单次答对不算 —— 4 选 1 本来就有 25% 蒙对率。犹豫（模糊）不增加也不清零连对。

「统计」页会把三种题型的正确率分开列 —— 再认与产出的差距一眼可见（我自己跑的数据：
英→中 88% / 中→英 65% / 拼写 43%）。还有「**最该复习的 20 个词**」，按客观正确率排，不按感觉。

## 怎么用

**双击 `启动.bat`**（会自己开浏览器）。就这一步。

关掉那个黑窗口就是停止服务。想下次不开浏览器就加参数：`启动.bat --no-open`。

想在**手机上刷**（手机和电脑连同一个 WiFi）：

```
启动.bat --lan
```

窗口里会打印一个 `http://192.168.x.x:8710/` 的地址，用手机浏览器打开即可。

> 需要本机装了 Node.js 18+。没有的话 `启动.bat` 会明确告诉你。

### 安卓手机版

`android/` 是安卓壳：**词库和助记都打包进 APK，装完就能用，完全不需要网络**
（APK 甚至没有申请联网权限 —— 「离线」是被系统强制的，不是靠约定）。

与网页版的差别：

- 同一份前端，不是另写的版本；电脑上改了界面，手机重新打包即同步。
- **手机默认不出拼写题**（要弹软键盘，键盘一顶就够不着按钮）。
  拼写是检索强度最高的题型，不想放弃的话去「统计 → 设置 → 拼写题」选「总是出」。
- 返回键：先收起答案/退出统计页，**再按一次才退出应用**（不会学习中途被弹出去）。

构建（本机）：

```bash
cd D:\code\DeepSeekHarness\cet-vocab-trainer\android
gradlew.bat assembleDebug
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

### 快捷键

| 键 | 作用 |
| --- | --- |
| `1`~`4` / `A`~`D` | 选择题选答案 |
| `0` | **我不会，直接看答案**（选择题和拼写题都有：按钮在选项下方） |
| `回车` | 拼写题提交 |
| `空格` | 学习卡「记住了，开始学」；看完答案后「下一个」；过词/浏览模式揭示释义 |
| `S` | 朗读当前单词 |
| `←` `→` | 乱序浏览模式前后翻 |

### 答案会停下来等你

**答对之后也不会自动跳走** —— 答案（单词 + 音标位置上的朗读按钮 + 完整释义）会一直留在屏幕上，
你看够了按 `空格` 继续。刷词的意义就在这几秒，自动翻页等于不给记忆留时间。

嫌手动太累可以在「统计 → 设置 → 答对后的记忆停顿」里改成 **3 / 5 / 8 秒**自动继续。

不知道答案时**不要瞎蒙** —— 点「我不会」（或按 `0`）。它按答错算（排期会更早再问你、
词会进错词本），但比蒙一个更诚实，也不会污染你的正确率。

## 四个模式

- **测验**（主线）—— 客观判分，三种题型智能混合，成绩进排期。
  难度随掌握度递进：新词与学习中只考「英→中」，连对 1 次后开始混「中→英」，连对 2 次后开始混拼写。
- **快速过词** —— 原来的自评卡片，**不计成绩、不改排期**，只用来快速过一遍词表并标记错词。
  想真正验证记住了没有，用「测验」。
- **乱序浏览** —— 打乱整本过一遍，标记「不认识」进错词本。
- **统计** —— 全部进度都在这里（顶栏那四个数字**点一下也能进**）：

  | 区 | 看什么 |
  | --- | --- |
  | **总进度** | 考过 / 记住了 的百分比 + 四态堆叠条（已记住 / 复习中 / 学习中 / 还没学）+ 学习天数、最长连续 |
  | **累计** | 累计答题 / 答对 / 答错、正确率、考过的词、记住了、今日各项、当前与最长连续 |
  | **最近 30 天** | 每天答题量柱状图，绿色是答对的部分、红色是答错 |
  | **题型正确率** | 英→中 / 中→英 / 拼写 分开算（再认与产出的差距一眼可见） |
  | **最该复习的 20 个词** | 按客观正确率排（要求答过 ≥2 次），不按感觉 |
  | **错词本** | 答错过的词，点一下听发音 |

每日额度：新词 20 个 / 复习 200 张（「统计 → 设置」里改）。
答错的词自动进**错词本**，间隔拉到 7 天以上时自动移出。

> ⚠️ 进度存在本机浏览器里。**换电脑、清缓存会丢**，请定期在「统计 → 学习记录」里导出备份。

## 词库

| 词库 | 词条数 | 来源 |
| --- | --- | --- |
| 大学英语六级词汇（乱序版） | 2083 | `大学英语六级词汇乱序版.pdf` |

词库是纯 JSON，放在 `assets/wordbooks/`，通过 `index.json` 注册 —— **加一本四级只需多放一个 JSON 并登记一行**，前端会自己读清单。

单条形如：

```json
{
  "word": "utmost",
  "def": "a.最外面的，最远的",
  "pos": ["a."],
  "page": 1,
  "source_word": "rmost"          // 源 PDF 里是坏的，这里是修复记录
}
```

> ⚠️ **源 PDF 本身是坏的**（不是扫描件，是被人重排过的表格版，含字符丢失、跨格错位、
> 水印混入）。提取管线做了 10 处首词修复，其中 1 处是推断。完整证据链见
> [docs/数据质量报告.md](docs/数据质量报告.md)。

**没有音标**：源 PDF 里没有，且本机拿不到离线音标库（外网走不通）。
点 🔊 用浏览器内置的语音合成朗读，不需要联网。

### 助记技巧

新词的学习卡、以及每次判定后的反馈里，会给出这条词的**记忆技巧**，分七类：
词根词缀 / 家族词 / 义项串联 / 词源故事 / 谐音 / 画面 / 搭配。

**徽记的颜色标的是「可信度」而不是类别**：🟢 确证（依据能在词形或同族词里自己验证）、
🟣 可信（事实可靠但看不见，如历史演变）、🟡 联想（纯联想，只为帮你记）。
生成策略是**真实优先**：有真词根/词源就讲，没有就用搭配或词形对比，**不编造词源**；
没有合适助记的词就不显示那块，不硬编。

**源书的错误会明确标出来**：这本 PDF 本身有词性标错与漏收义项（如 `dignity` 标成 `a.`、
`over` 只收了「在…时」），修正过的条目卡片下方会显示
「⚠ 本条已修正：原书写作…」—— 你是照着书背的，不一致就必须让你知道。

进度：**全库 2083 词 100% 覆盖**，助记共 2083 条（`node tools/validate_tips.mjs --progress` 现读）。
若要继续扩别的词库（CET-4 等），按 `tips/<词库id>.json` 的约定加文件即可。

## 开发者：重建词库 / 跑门禁

```bash
# 重建词库（需要 Python 3 + PyMuPDF，以及源 PDF 在默认路径）
python tools/extract_pdf.py
python tools/build_wordbook.py

# 离线拼写校验（可选，用 vim 自带词典，无需联网）
python tools/spellcheck.py

# 门禁：本地三道里的前两道（秒级，不需要浏览器）
node tools/verify.mjs --data

# 门禁：全部三道（另开一个窗口先跑 node server.mjs --no-open）
node tools/verify.mjs

# 单独修 .bat 换行（LF → CRLF；Windows 的 cmd 只认真 CRLF）
node tools/check_launcher.mjs --fix
```

三道门禁分别是：**启动器**（`.bat` 纯 ASCII + 全 CRLF + 真去起 server）、
**数据**（词库 13 项形态与修复项校验）、**浏览器**（CDP 驱动真 Chrome 跑 113 项交互与计算样式断言）。

`tools/cdp_probe.mjs` 会用本机 Chrome 的无头模式真跑一次页面，
读**计算样式**、派发真实键盘事件、核对 localStorage，并输出截图到 `.tmp/`。
它比「HTTP 200」可靠得多 —— 实测抓到过「释义在未揭示时就可见」这类只有渲染后才暴露的 bug。
